# _bmad-output

Sortie des skills BMad pour ce projet (`output_folder` dans `_bmad/config.toml`).

Vide au départ, et c'est voulu : les artefacts BMad de MyPaddock — PRD, recherches
marché, brainstormings roulage moto — décrivent un autre produit. Les recopier ici
aurait donné aux agents BMad une spécification étrangère à lire comme si c'était
celle de la plateforme UTI. Les répertoires attendus par la configuration existent,
les skills les remplissent au fur et à mesure.

- `planning-artifacts/` — PRD, epics et stories, recherches (`modules.bmm.planning_artifacts`)
- `implementation-artifacts/` — sorties d'implémentation (`modules.bmm.implementation_artifacts`)
